# MindFlow
Ce projet est la maquette d'une application de bien-être mental.
À travers un design intuitive et personnalisée, il apporte aux utilisateur souffrant de surcharge mentale, stress, difficulté à décrocher du numérique , équilibre mental et une routine anti-stress

# Commencer le projet
Afin de mener à bien ce maquette, il faut d'abord identifier ce que cherche un utilisateur sur ce genre d'appli et quel design lui apporterait
